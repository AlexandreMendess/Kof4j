# CURRENT_STATE.md — Kof Runtime State

**Date:** September 2, 2026
**Status:** Phase F complete + 0.4.0-beta (free-list GC + mark-sweep, spawn pthread, FP XMM, complete JSON); re-synced 17/09

---

## 1. Summary

Kof has a runtime formalized via a semantic ABI. NativeBackend implements runtime functions in embedded assembly. The JVM backend delegates to JVM facilities.

---

## 2. State of kof-runtime

```
kof-runtime/
  pom.xml          ← exists, empty Maven module
  src/main/java/   ← empty (no .java files)
```

The `kof-runtime` module exists as a Maven project but contains zero code.
The native runtime functions are generated by `NativeRuntime.java` in the compiler.

## 4. IR × Runtime Operations

### KofNewObject
- **JVM**: `NEW` bytecode → JVM allocates
- **Native**: `kof_alloc(size)` → heap allocation

### KofLoadField / KofStoreField
- **JVM**: `GETFIELD`/`PUTFIELD`
- **Native**: `movq offset(%rax), %rax` / `movq %rax, offset(%rcx)`

### KofNewArray
- **JVM**: `NEWARRAY` bytecode
- **Native**: `kof_array_alloc(length, element_size)`

### KofArrayLoad
- **JVM**: `IALOAD`/`LALOAD`/etc.
- **Native**: `kof_array_get(array, index)` with bounds check

### KofArrayStore
- **JVM**: `IASTORE`/`LASTORE`/etc.
- **Native**: `kof_array_set(array, index, value)` with bounds check

### KofArrayLength
- **JVM**: `ARRAYLENGTH` bytecode
- **Native**: `kof_array_length(array)`

### KofDup
- **JVM**: `DUP`
- **Native**: `movq (%rsp), %rax; pushq %rax`

### KofCall (FUNCTION)
- **JVM**: `INVOKESTATIC`
- **Native**: `call function_name`

### KofCall (CONSTRUCTOR)
- **JVM**: `INVOKESPECIAL`
- **Native**: emitted as a native function

## 5. Implementation Decisions

1. **Heap allocation** — objects and arrays are allocated on the heap via `kof_alloc`
2. **8-byte header** — type_id (4) + flags (4) for objects
3. **16-byte array header** — type_id (4) + flags (4) + length (4) + elem_size (4)
4. **Virtual dispatch** — vtable per class (Phase F.4); interfaces via vtable (F.5)
5. **Fatal errors** — runtime errors terminate the process
6. **UTF-8 strings** — immutable, with null terminator
7. **Fields padded to 8 bytes** — consistent alignment

## 7. What Does NOT Work

| Feature | State | Reason |
|---------|--------|--------|
| Generics | ✅ | Erasure (classes and functions) |
| Collections | ✅ | `List<T>`, `listOf`, for-in |
| Static fields | ⚠️ | Limited semantics |
| Boxing/Unboxing | ✅ | Native no-op (64-bit slots); JVM via valueOf |
| Type casting | ✅ | `as` (native no-op, no verification) |
| instanceof | ✅ | `kof_super_table` |
| GC | ⚠️ | free-list `kof_free_head` (`mmap` reuse) + mark-sweep implemented 03/09 (manual `kof_gc_collect_now`); auto-collect on exhaustion ✅ 19/09 (D1-A, §260 CLOSED) |
| `spawn`/`await` (concurrency) | ✅ | `pthread_create` + trampoline + `pthread_join` + thread-safe allocator (futex) — 31/08 (CONC001) |
| FP (Float/Double) | ✅ | Real XMM (`vcvtsi2sd`/`mulsd`), dtoa via `snprintf` — 31/08 (FLT001) |
| JSON objects/arrays | ✅ | objects/records + arrays `Int/Long/Bool/String/Double` — 31/08 (JSN001/002/003) |
| Default methods in interfaces | ⚠️ | Partial support |
