# stdlib/ — um capítulo por namespace

Todo namespace da stdlib do Kof tem capítulo próprio aqui. As tabelas de
funções são **medidas dos dispatchers reais** (`StdCatalog` / `Kof*.java`) —
o conjunto de capítulos é o contrato 1:1 com a implementação. As faces de
paridade são rastreadas em
[`docs/development/parity/PARITY-GAPS.pt_BR.md`](../../docs/development/parity/PARITY-GAPS.pt_BR.md)
(paridade total é o impeditivo da 0.5.0).
